# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately rather than opening a public issue.

You can report it by:

- Contacting the [cloudpunk-io/security](https://github.com/orgs/cloudpunk-io/teams/security) team, or
- Emailing [andres@cloudpunk.io](mailto:andres@cloudpunk.io)

Please include as much detail as possible, including steps to reproduce, potential impact, and any relevant logs or screenshots.

## What to Expect

We will acknowledge your report as soon as possible and work with you to understand and address the issue. Please allow reasonable time for a fix before disclosing the vulnerability publicly.
